# 运动场与水域的展示空间规则

入口：`/mecoffe3d`；素材库：`/mecoffe3d/assets`。建筑仍为 YuLan 风格，人物仍为 Rocketbox 写实模型。无需新增依赖或重新下载 OSM。

## 场地与模型

| 原型 ID | 实际生成内容 | 定位与边界 |
| --- | --- | --- |
| `landcover.sports.track400` | 4/6/8 道变体、实体跑道、分道线、内场与球门 | 只在用户标注的 `way/1501639765` 足球场外围使用；按足球场朝向和尺寸适配，不将其他足球场自动认定为 400m 跑道 |
| `landcover.sports.basketball` | 实体场地、篮球标线、篮架、篮板和篮网 | 对应 OSM `sport=basketball` 区域；按区域旋转、缩放与排布 |
| `landcover.sports.tennis` | 实体场地、单双打边线、发球线和网柱/球网 | 对应 OSM `sport=tennis` 区域 |
| `landcover.sports.badminton` | 实体场地、单双打边线、发球线和网柱/球网 | 对应 OSM `sport=badminton` 区域 |
| `landcover.water` | 开挖后的岸坡、变化湖底和半透明水面 | 采用原永怀湖轮廓；水深仅为展示参数 |
| `road.bridge` | 有厚度桥面、两岸坡道、护栏及桥墩 | 由现有跨水道路与湖面交集推定；不是新增实测桥梁 |

原型位于 `catalog.json`，均可在素材库旋转预览及切换变体。没有引入第三方美术下载，程序模型和 OSM 几何分别记录许可。跑道最外圈也参与装饰避让，树木、灯、长椅不得落在跑道上。

跑道原型采用内沿半径 36.5m、直道 84.39m、每道 1.22m；第一道测量线距内沿 0.3m，对应约 400m。参数参考 [World Athletics 官方设施手册](https://worldathletics.org/download/download?filename=7d39b677-8043-45f4-89f4-6c8814023057.pdf&urlslug=Track+and+Field+Facilities+Manual+2019+Edition+-+Chapters+1-3)。这是模型原型尺寸，校园实例按用户要求进行展示缩放，不能反推实地周长。篮球原型 28×15m，参考 [FIBA 场馆设计指南](https://www.venueguide.fiba.basketball/vanue-design)；网球双打原型 23.77×10.97m，参考 [ITF 术语说明](https://www.itftennis.com/en/about-us/organisation/tennis-glossary/)。场地数量、间隔和缓冲区是展示排布，不是 OSM 确认的实地数量或合规体育设施设计。

## 水深和道路高差

- 草坪展示高程 0.62m；水面 −0.55m；岸坡向内下凹约 1.27m。水面保持水平，湖底根据距岸距离和固定函数起伏。
- 设定水深约 0.22–2.8m，近岸浅、部分湖心较深。水面半透明，湖底顶点有真实高差；草坪和校园台地在水域轮廓处做几何扣除，不再用平面覆盖地面。
- 斜跨湖面的 `way/1242496025` 增加示意桥、坡道、护栏和桥墩。桥面高度 1.05m。
- `way/1242495999` 的原始 `layer=-1` 保留，原数据没有 `tunnel=yes`。按用户反馈在展示层保留灰色跨水通行面，高度 0.28m，避免水面覆盖道路；不宣称这是已核实的桥或隧道。
- 这些高度、桥宽、结构和深度都是展示设计，不用于现实安全判断或实地导航；未来有测绘数据时应单独提供权威高程/水深输入。

## 行走约束和原始数据边界

`campus3dSpatial.js` 从水域与现有道路生成独立的运行时 `waters/bridges`。`Campus3DScene` 将建筑和水域共同传给站位、显示绕行、局部避让及逐帧移动检查。

1. 开阔水面禁止站人；桥面或抬高通行面是水域内的例外区域。
2. 除了检查起终点，还求线段与水岸/桥边的交点，检查整个移动线段。两个端点在岸上也不能跨帧穿过湖面。
3. 显示路线需要绕行时使用桥头及岸外候选点。脚下接触范围不能离开桥面；人物高度随坡道变化。人群间距与扫掠避让继续生效，狭窄处等待通过。
   初始放置或相机尺度变化时，静止站位额外预留靠墙通道，避免一名静止人物封死其他人的出发口。固定相机下仍靠连续移动避让，不通过运行中的瞬移解除拥堵。
4. 为全景辨识而放大的人物具有夸张的分离半径；与水面的脚下接触半径取其 0.18 倍，不能将它解释为实测人体尺寸。人物之间仍按完整分离半径保持间距。
5. `routeBetweenMappings()` 的原始 A* 路线保持不变，只约束其显示副本。站位、桥、绕岸和排队不会改变事件、订单、销量或 OASIS 决策。顶部位置示意提示保持原文。

`campus3dSpatial.test.js` 覆盖开阔水面、桥边、连续扫掠、绕行、几何开挖和数据不变性。`campus3dSports.test.js` 覆盖尺寸、设备、区域排布、装饰避让和素材变体。`campus3dTraffic.test.js` 用真实校园 100 人、12 笔并发购买逐帧验证全程无水上行走，并要求实际经过桥面；同时验证完整订单收据、归位和原始 A* 不变。
