# 校区活动边界、校园人物与三维素材

入口：`/mecoffe3d`；默认素材库：`/mecoffe3d/assets`。保持原 OSM、地点映射、A* 图、三种回放数据及二维页面不变；不需要模型 API。

## 校外人物的原因和修正

之前按要求只在显示层裁掉未建设地块，原始 OSM 边界保留。人物碰撞只约束建筑和水域，站位搜索却没有校区边界条件；放大人物、让出靠墙通道后，一部分站位被排到校外。不能以隐藏这些人物或扩大校园来掩盖越界。

现在将**当前显示副本中的建成区校界**加入空间规则，移除地块不参与站位或显示路线。人物完整的显示碰撞半径必须位于校界内，连续移动线段也检查凹边与孔洞，不能因为两个端点合法就穿过校外。源边界与原始 A* 路径不修改；必要时约束的是动画的显示副本。

基础显示半径从8缩为6米，仍覆盖归一化后的身体网格，并保留角色之间的扫掠间距。初始站位和相机尺度改变时预留通道；超出校内安全容纳尺度时限制展示放大，回退到已验证尺度。固定相机下不通过瞬移解决拥堵。所有100个主体都有校内显示位置，不是仅把校外人藏起来。

## 校园人物

默认改用 [VALID 作者发布库](https://github.com/google/valid-avatar-library)，固定提交 `c76d2547b5b464415283169d18dffb16bb584eee`，MIT，Copyright 2022 Tiffany Do。导入9套带骨骼和内嵌贴图的原始 FBX：5套便装、4套商务装。每个文件校验上游 Git blob、SHA-256 与大小；只保存完整验证成功的模型，不声称导入整个210人库。

- Asian 与 male/female 是上游**合成模型**的明确目录/文件标签；不是从图像推断，也不表示画像主体真实族群或国籍。
- 98位师生的显式 `gender=m/f` 与模型性别逐一匹配；本科生/研究生穿便装，教师穿通勤装。
- 两个商家代理没有性别资料，店员外观只作示意，详情显示“未提供”，不补写画像性别。
- 型号按ID稳定选择，外观可以重复，不再为了“每个人不重复”而使用军警、飞行员或儿童模型。
- 115套 Rocketbox 原始库与许可继续保留，可在素材库切换“全部原型与原始素材”浏览；不会自动混入校园。

兼容处理只发生在运行时：合并 FBX 导入器产生的同姿态重名骨骼，保留身体与眼睛，去掉室外回放不需要的口腔内部和作者灯光；合并重复顶点，按实际骨架左右方向放松手臂，再驱动站立、行走和持杯。原始FBX不改写。仍保留最多3路加载、按需显示、暂停停止绘图和最多8个隐藏预热实例。

## 原生三维植被

采用 [Kenney Nature Kit 2.1](https://kenney.nl/assets/nature-kit)，CC0-1.0。保存5种乔木、3种灌木的原始 GLB，全部是有厚度的三维顶点/三角面，没有树木图片平面；原包 SHA-256 为 `fa7974a0d342bfe63c38664ba9f8ec1a4aab8ea25f099bdc56870e33588c4d9d`。

模型以实例化网格批量绘制，沿用已有避让逻辑和高低画质控制。YuLan 建筑保持原样，当前场景不再用 YuLan 像素浮雕替换树木。树种名称只描述素材，不声称对应实地树种或种植位置；图例仍标“装饰”。

完整目录349项，默认“当前校区使用的素材”207项。可搜索、分类、旋转，查看原型、来源和许可。所有运行素材本地读取，不需要访问上游网站。

## 离线检查与重建

```powershell
python -X utf8 adapter/import_campus_assets.py
python -X utf8 adapter/build_asset_catalog.py
python -X utf8 -m unittest discover -s adapter -v
cd frontend
npm test
npm run build
```

`import_campus_assets.py --nature-zip <原包>` 可从校验过的 Kenney 原包恢复已登记模型；`--valid-dir <原始下载目录>` 可从已下载文件恢复9套人物。错误归档或哈希不符时不覆盖对应素材。许可和清单随仓库保存。

边界与水域仍是**展示空间规则**，不是已经接入 OASIS 的权威物理环境。没有真实入口、测绘高程或水深数据时，不能据此认定现实通行条件；顶部原有位置示意提示保持不变。
