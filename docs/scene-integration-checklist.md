# 三维 / GIS 接入联调清单

适用时机：学弟的 PR 经 Alemax067 审查、合并并部署后。师兄同意接入方向不等于已经部署；首次验收由部署者提供网站入口与一份获准查看的测试会话。默认关系网络仍然可用，纯舆论实验不要求地图。

## 准备

- [ ] 登录团队网站，记下测试会话、本次配置和运行编号，以及部署者提供的场景包版本。使用获准的账号和数据；不要把 Cookie、密码、人物文件或截图发到公开仓库。
- [ ] 配置预览用一份已完成“角色”和“关系网络”的配置；回放用一份已结束的运行。由开发者给出预期人数、关系数、成功订单数、被拒/未知数，作为核对依据。

## 配置预览：还没运行，也能看对同一批人

- [ ] **在哪里点：** 配置页生成关系网络后，点“查看三维 / GIS”（按钮实际名称以部署页面为准）。**应看到：** “配置预览 · 尚未运行模拟”，人数、关系数与该配置一致；事件和订单均为 0。
- [ ] **在哪里点：** 打开人物列表，选择一个人，再点其所在楼栋。**应看到：** 人物画像与配置一致，楼内名单包含此人；楼内人数加室外人数等于总人数，人物能定位。
- [ ] **在哪里看：** 页面顶部、地图说明。**应看到：** 人物楼栋和走路路线为示意、OASIS 没有位置数据；不能把示意位置当成真实住址。

## 终态回放：播放的是这一次运行

- [ ] **在哪里点：** 某次已结束运行的结果页，点“三维 / GIS 回放”，把进度条拖到最后。**应看到：** 人数、成功订单数与该运行一致；被拒/未知动作单独标注，被拒购买不增加订单、不取杯。
- [ ] **在哪里点：** 选取一个人物，查看动作和“数据详情”；切换三维/GIS。**应看到：** 两边使用同一份运行、中文角色名和角色人数一致；长说明可展开，数据详情仍保留原始 `role` 编号，不靠英文角色名猜翻译。
- [ ] **在哪里点：** 一份失败但有终态部分轨迹的测试运行。**应看到：** 明确的“不完整/部分记录”提示，仅播放已有记录，不补成完整天数；没有可用轨迹时说明原因，不展示另一次运行。
- [ ] **在哪里核对（开发者协助）：** 结果页运行编号与浏览器 Network 面板里的运行详情。**应看到：** 角色说明和计划请求中的 `config_id` 来自该运行详情；轨迹、冻结快照、计划的 `snapshot_id/revision` 一致，计划编号/版本也一致。让会话当前选中另一个配置后再打开旧运行，不能串用新配置。
- [ ] **在哪里测（测试环境，由开发者模拟）：** roles 接口返回 404、未完成或格式错误，再打开同一次回放。**应看到：** 回放照常；优先保留冻结快照已有说明，否则显示原名；人数和订单不变。不要在生产环境删除数据制造故障。

## 权限、刷新与资源

- [ ] **在哪里点：** 退出登录后直接打开原场景链接。**应看到：** 401 对应“登录失效”提示，不显示空场景冒充成功；roles 单独返回 401 时同样提示登录失效。
- [ ] **在哪里测（开发者提供链接）：** 不存在或无权查看的会话/运行。**应看到：** 404 对应“不存在或无访问权限”说明，不泄露他人数据。
- [ ] **在哪里点：** 一份还在排队/运行中的回放入口。**应看到：** 提示尚未结束/产物未就绪；产物接口返回 409 时同样明确提示，不白屏、不加载旧结果。
- [ ] **在哪里点：** 在三维与 GIS 间切换，然后各按一次浏览器刷新。**应看到：** 地址里的 `session + config` 或 `session + run` 保留，数据和登录状态一致，没有回到另一场模拟。
- [ ] **在哪里看（开发者协助）：** F12 → Network，刷新 `/scene/` 页面，再打开人物、素材库及“来源与许可”。**应看到：** JS、CSS、地图、模型、纹理、许可资源无 404；缺失 JSON 不返回 HTML；Console 没有未处理报错。仅在故障测试中预期的 API 错误不算资源故障。
- [ ] **在哪里核对（开发者协助）：** 静态 `/scene/` 目录、公开部署产物及数据请求。**应看到：** 静态包只有程序、必要素材、中科大地图和标明合成的样例；真实人物与轨迹经同源、登录保护的 API 读取，不进入公开 Pages。退出登录/换成无权限账号后不能读取原私有产物。
- [ ] **在哪里点：** 回到团队原来的关系网络和模拟页面；在测试环境模拟地图加载失败。**应看到：** 主流程照常，地图处提示“暂无场景/加载失败”。若可选模式/故障隔离尚未接好，记为待完成，不当作已通过。

## 记录与交接

记录部署版本、通过项、未通过项和复现步骤；问题注明在哪个配置/运行和哪个页面发生。真实数据截图只在团队授权范围内传递。接口路径与部署方式以 PR 审查结果为准；全部问题确认后再宣布“接入完成”。
