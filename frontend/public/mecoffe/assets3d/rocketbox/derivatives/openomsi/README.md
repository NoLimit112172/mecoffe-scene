# openOMSI derivative colour textures

Original models/textures: Microsoft Rocketbox Avatar Library, MIT.
Original repository revision: 0943055db6ec570bcef9f2c8b41c9e5467c808f9.

Intermediate archive: https://github.com/openOMSI-org/openOMSI/releases/download/avatars-1/openOMSI-avatars-1.zip
Release tag avatars-1 targets f4841225a413a32103df312dcaa0e30dc81cbd76.
GitHub-reported archive SHA-256: ead00bbfbf66165336dcd40323569840c18e148ee79c3e7d097d198ad4b12d6a.
Only selected ZIP entry ranges were fetched; the complete archive hash was not locally verified.
Each fetched JPEG/PNG entry is verified by ZIP CRC32, decoded dimensions/format, and recorded actual SHA-256.
JPEG colour images are already lossy derivatives; alpha images remain PNG.
Local outputs use LANCZOS resizing (head/shared atlas 1024px; body/opacity 512px) and lossless PNG encoding.
The original TGA was not downloaded or locally hash-verified for these derivatives.
No UV layout was changed. Standard FBX files remain the separately verified original Microsoft files; facial FBX from this package is not used.
Per-image model records preserve canonical source URLs and Git blob identities, with source_sha256=null and complete derivative provenance.
Conversion script reference: https://github.com/openOMSI-org/openOMSI/blob/07a101ab5d0b5c8f54debefc38ea2584de23695f/tools/avatars/build_pack.py
The script was committed after release; archive CREDITS independently describes the same image conversion.
